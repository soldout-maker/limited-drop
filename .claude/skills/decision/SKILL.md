# /decision

[docs/decisions.md](../../../docs/decisions.md)는 팀의 기술 결정 기록이다.

## 상태 값

`결정 필요` → `초기 제안` → `초기 선택` → `확정`

- **`확정`은 사용자가 "팀이 합의했다"고 명시했을 때만** 쓴다. Claude가 추천했다는 이유로 확정하지 않는다.

## 절차

1. decisions.md를 읽고, 요청이 기존 항목(D-0XX)의 갱신인지 새 항목인지 판단한다.
2. **선택지 비교를 요청받은 경우**: 이 프로젝트 맥락(2인 개발, NestJS + Next.js, 한정 드롭 / 대기열 / 결제 가능성)에서 선택지별 장단점을 짧게 정리하고 추천안을 제시한다. 문서에는 `초기 제안`으로만 기록한다.
3. **결정을 기록하는 경우**: 해당 항목의 `현재 제안`, `결정 이유`, `결정 상태`를 갱신하고 문서 위쪽의 **요약 표도 함께** 고친다. 이전 결정을 뒤집는 경우 지우지 말고 이유에 변경 이력을 한 줄 남긴다.
4. 새 항목은 마지막 번호 다음 번호로, 문서 하단의 양식을 따른다.
5. 결정이 다른 문서에 영향을 주면 함께 고칠지 묻는다:
   - README.md의 기술 스택 표
   - CLAUDE.md의 "미결정 기술" 목록
   - `.env.example` (예: DB 결정 → `DATABASE_URL` 주석 해제)
6. 문서만 수정한다. 결정된 기술의 설치나 코드 작성은 별도 작업으로 진행한다.
